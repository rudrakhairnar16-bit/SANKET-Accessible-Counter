# SANKET — Pre-Submission Baseline

This file describes the current release baseline. Historical PASS claims from older archives are intentionally not treated as current verification evidence.

## Current state

SANKET is an accessibility-first public-service counter prototype with:

- ISL/ASL metadata-based sign selection
- phrase cards and typed communication
- staff/citizen conversation flow
- local session timing and activity metrics
- large-text and high-contrast controls
- optional still-image recognition integration
- confidence-aware recognition UX
- security and provenance documentation

## Evidence boundary

The current environment verified static audits and source-level hygiene. Full npm runtime verification is blocked by an incomplete dependency installation after an environment transport timeout.

Real Deaf/HoH participant testing is intentionally skipped.

Expert linguistic validation and SANKET-specific model evaluation are not represented as completed.
