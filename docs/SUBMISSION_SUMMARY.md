# SANKET — Submission Summary

SANKET is an accessibility-first public-service counter prototype designed to reduce communication friction between Deaf/Hard-of-Hearing citizens and public-service staff.

## What the prototype demonstrates

- Accessible counter workflow.
- ISL/ASL-labelled sign concept browsing.
- Searchable sign selection and draft confirmation.
- Staff quick-response and typed-message workflows.
- Text-to-speech where supported by the browser.
- Session timing and local activity metrics.
- Large-text, contrast, keyboard and semantic accessibility features.
- Optional consent-based still-image recognition integration.
- Confidence-aware recognition UX that avoids automatic uncertain translation.

## Honest evidence boundary

The prototype does not claim certified sign-language translation, expert linguistic validation, SANKET-specific model accuracy, or real Deaf/HoH participant testing.

Real Deaf/HoH participant testing is intentionally skipped for this submission cycle.
